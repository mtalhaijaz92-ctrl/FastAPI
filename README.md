
# 🎓 Student Management API

FastAPI aur Pydantic ka istemal karte hue banayi gayi ek simple, lightweight, aur beginner-friendly RESTful API jo student records ko manage (CRUD operations) karne ke liye use hoti hai.

---

## 🚀 Features

- **Get All Students:** Saare students ki list dekhain ya city ke name se filter karain.
- **Get Single Student:** Student ID ki madad se specific record fetch karain.
- **Create Student:** Naya student add karain (Pydantic validation ke sath).
- **Full Update (PUT):** Student ka poora record update karain.
- **Partial Update (PATCH):** Student ki specific field (Name, Age, ya City) update karain.
- **Delete Student:** Record ko memory se delete karain.
- **Interactive API Docs:** Automatic Swagger UI aur ReDoc documentation.

---

## 🛠️ Prerequisites & Tech Stack

- **Python:** 3.8 یا us se new version
- **Framework:** FastAPI
- **Data Validation:** Pydantic
- **ASGI Server:** Uvicorn
